# Как проверить сайт локально

## Запуск

В корне проекта выполните:

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run streamlit_app.py
```

Откройте `http://localhost:8501`. Остановить сайт можно сочетанием `Ctrl+C` в терминале.

## Быстрая ручная проверка

1. На странице «Обзор» переключите обычный и стрессовый сценарии.
2. На странице «Стратегия» измените объём, нажмите «Применить решения», затем «Пересчитать» слева.
3. Откройте «Результаты» и проверьте графики, таблицы и читаемость карточек.
4. В «Сценариях» сравните варианты A, B и C.
5. В «Рисках» запустите расчёт портфеля рисков и проверку чувствительности.
6. В «Исследованиях» добавьте источник или следующий год и рассчитайте расширенный вариант.
7. В «Данных и экспорте» скачайте JSON плана и CSV-файлы.

## Автоматические тесты

```bash
python3 -m pytest
python3 tools/validate_participant_repo.py
```

Некоторые расчёты рисков и сценариев могут занять несколько секунд — это нормально.
