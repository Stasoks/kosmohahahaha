# Как проверить сайт локально

## Запуск

В корне проекта:

```bash
python3 -m pip install -r requirements.txt
python3 -m streamlit run streamlit_app.py
```

Откройте `http://localhost:8501`. Остановка: `Ctrl+C`.

## Быстрая ручная проверка

1. В левом меню выберите другую стратегию и нажмите «Выбрать и пересчитать». Название текущей стратегии и показатели должны измениться.
2. На «Обзоре» переключите обычный и обязательный стресс. Это меняет условия расчёта, а не сам план.
3. На «Стратегии» измените решение, примените его и убедитесь, что появляется сообщение о несчитанных изменениях. Затем нажмите «Пересчитать».
4. На «Результатах» проверьте таблицы, графики и нарушения.
5. На «Сценариях» сравните A, B и C; C является отдельным заранее адаптированным планом.
6. На «Рисках и чувствительности» запустите риск и проверку чувствительности.
7. На «Исследованиях» добавьте источник или следующий год и рассчитайте расширенный вариант.
8. На «Данных и экспорте» скачайте JSON плана и CSV/ZIP.

## Автоматическая проверка

```bash
python3 -m pytest
python3 tools/validate_participant_repo.py
```

Тяжёлые расчёты сценариев и рисков могут выполняться несколько секунд.
